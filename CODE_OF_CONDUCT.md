# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and inclusive environment for everyone who participates in this project.

We expect all contributors, maintainers, and community members to treat each other with respect and professionalism, regardless of experience level, background, identity, or point of view.

## Our Standards

Examples of behavior that contribute to a positive environment include:

* Being respectful and considerate of others.
* Using welcoming and inclusive language.
* Providing constructive and helpful feedback.
* Accepting different opinions and perspectives.
* Focusing on what is best for the project and its community.
* Taking responsibility for mistakes and learning from them.

Unacceptable behavior includes:

* Harassment, discrimination, or personal attacks.
* Trolling, insulting, or deliberately provoking others.
* Publishing or sharing someone's private information without permission.
* Sexualized language or unwanted sexual attention.
* Threats of violence or intimidation.
* Any other behavior that would reasonably be considered inappropriate or harmful in a professional community.

## Scope

This Code of Conduct applies to all project spaces, including:

* GitHub issues and pull requests.
* Discussions and comments.
* Code reviews.
* Project-related communication and events.

This Code of Conduct also applies when an individual is officially representing the project or its community.

## Enforcement

Project maintainers are responsible for clarifying and enforcing the standards described in this Code of Conduct.

If you experience or witness unacceptable behavior, please report it to the project maintainers through the appropriate private communication channel.

Reports will be reviewed and handled as fairly and confidentially as possible. Maintainers may take any action they consider appropriate, including warnings, removal of inappropriate content, temporary restrictions, or permanent removal from project spaces.

## Reporting

If you encounter behavior that violates this Code of Conduct, please report it privately to the project maintainers.

When making a report, please provide as much relevant information as possible, including:

* A description of the incident.
* When and where it occurred.
* The people involved.
* Any relevant links, screenshots, or other evidence.

Please do not publicly disclose sensitive information about the people involved.
